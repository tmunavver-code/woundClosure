## 2. Bug Fixes

### 2.1 GraphicsPlaceholder Error (`myMainClassical.m`, `my2MainClassical.m`)
- **Problem:** `plot3Dtissue()` returns a `gobjects` array where some entries are `GraphicsPlaceholder` (for cells with < 3 vertices that are skipped). Calling `set(p_wound, 'FaceColor', ...)` on these placeholders crashes MATLAB.
- **Fix:** Changed to `set(p_wound(isgraphics(p_wound)), 'FaceColor', ...)` to filter out invalid handles before setting properties.
- **Applied to:** Both `2D_VX_model/myMainClassical.m` and `2D_VX_model_reverted/my2MainClassical.m`.

### 2.2 Auto-Formatter Corruption
- **Problem:** An IDE auto-formatter (likely a C/JS formatter) corrupted `getAreaDerivative.m` and `getCellDataforPlottingwithoutPeriJumps.m` — changing `%` comments to `//`, splitting function signatures across lines, etc.
- **Fix:** Restored `getAreaDerivative.m` manually and reverted `getCellDataforPlottingwithoutPeriJumps.m` via `git checkout`.

## 5. Edge Force Analysis — New Feature

The existing code only computed **vertex-level forces**. Three new files were created to compute and visualize **edge-level force distribution**:

### New Files

| File | Purpose |
|------|---------|
| `getEdgeForces.m` | Computes per-edge force decomposition: perimeter tension, area pressure, purse-string tension, tangential/normal force vectors |
| `plotEdgeForces.m` | Visualizes edge forces as color-coded maps (blue→white→red diverging colormap) and quiver arrow plots |
| `runEdgeForceAnalysis.m` | Standalone script: runs full simulation, captures edge force snapshots at 5 timesteps, saves all results |

### Output Files (in `results/edge_forces/`)
- `edge_forces_final_4panel.png` — Perimeter tension, purse-string tension, total tension, area pressure
- `edge_force_vectors_final.png` — Tangential (red) + normal (blue) force arrows
- `edge_tension_evolution.png` — Tension maps at 5 timesteps across the simulation
- `energy_vs_time.png` — Energy convergence
- `edge_force_workspace.mat` — Full workspace for further analysis

### Physics Behind Edge Forces
In the classical vertex model with energy `E = Σ [ka(A-1)² + (1/rstiff)(P-p0)²]`:
- **Perimeter tension** `T = 2/rstiff × (P - p0)` acts along each edge (contractile if P > p0)
- **Area pressure** `P_area = 2·ka·(A - 1)` acts normal to each edge (expansive if A > 1)
- **Purse-string tension** `λ(t)` acts only on wound margin edges (always contractile, ramps up over time)
